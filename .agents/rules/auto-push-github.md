# Auto-Commit and Push to GitHub

Whenever you complete code modifications or file changes in this workspace (`NIDO-TECHNOLOGIES`):
1. Immediately stage all relevant modified/added files (`git add -A`).
2. Create a clear, concise commit message summarizing the changes (`git commit -m "..."`).
3. Push the commit directly to GitHub (`git push origin main`) without waiting to be asked.

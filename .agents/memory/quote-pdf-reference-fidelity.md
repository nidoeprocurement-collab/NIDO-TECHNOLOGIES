name: Quote PDF reference fidelity
description: The visual contract for quotation PDF downloads based on the uploaded estimate reference.
---

Quotation PDFs are governed by the uploaded estimate reference: retain its A4 portrait page, Helvetica typography, monochrome gray styling, spacing, header/company blocks, estimate information box, totals panel, terms, signature line, and footer. Requested changes should be isolated to the item table and its data mapping.

**Why:** The user explicitly requires pixel-level visual consistency with the reference and only authorized a change to the item-list columns.

**How to apply:** When changing quote PDF output, compare against the reference image first and avoid altering the surrounding document shell; keep the item table inside the original page margins even when additional columns require compact sizing.
